# 系统要求

在安装 V2Board 之前，请确保您的服务器满足以下要求。

## 服务器配置

### 最低配置

- **CPU**: 1核
- **内存**: 1GB RAM
- **硬盘**: 10GB 可用空间
- **带宽**: 1Mbps

### 推荐配置

- **CPU**: 2核或以上
- **内存**: 2GB RAM 或以上
- **硬盘**: 20GB SSD
- **带宽**: 10Mbps 或以上

## 软件环境

### 操作系统

支持以下操作系统：

- **Ubuntu** 20.04 / 22.04 LTS （推荐）
- **Debian** 10 / 11
- **CentOS** 7 / 8
- **其他** Linux 发行版理论上也支持

### Web 服务器

以下任一即可：

- **Nginx** 1.18+ （推荐）
- **Apache** 2.4+
- **Caddy** 2.0+

### PHP 环境

- **PHP 版本**: 8.0 / 8.1 / 8.2 （推荐 8.1）
- **必需扩展**:
  - `php-fpm`
  - `php-mysql` / `php-mysqli`
  - `php-curl`
  - `php-gd`
  - `php-mbstring`
  - `php-xml`
  - `php-zip`
  - `php-bcmath`
  - `php-redis` （推荐）

### 数据库

- **MySQL** 5.7+ / 8.0+ （推荐）
- **MariaDB** 10.3+

### 其他依赖

- **Composer** 2.0+
- **Redis** 5.0+ （推荐用于队列和缓存）
- **Supervisor** （用于管理队列进程）

## 网络要求

### 端口

确保以下端口可用：

- **80** - HTTP
- **443** - HTTPS
- **3306** - MySQL (可限制为本地访问)
- **6379** - Redis (应限制为本地访问)

### 域名

- 需要一个已解析的域名
- 建议配置 SSL 证书（可使用 Let's Encrypt 免费证书）

## 权限要求

- **Root 权限** 或 **Sudo 权限** 用于安装软件包
- **Web 用户权限** (如 www-data, nginx) 用于运行应用

## 检查清单

安装前请确认：

- [ ] 服务器配置满足最低要求
- [ ] 操作系统已更新到最新版本
- [ ] 已准备好域名并完成 DNS 解析
- [ ] 具有服务器 Root 或 Sudo 权限
- [ ] 网络连接稳定，可访问外部资源

## 常见问题

### Q: 可以在虚拟主机上安装吗？

不推荐。V2Board 需要运行队列服务和定时任务，虚拟主机通常没有足够的权限。建议使用 VPS 或云服务器。

### Q: Windows 服务器支持吗？

不推荐。虽然理论上可行，但大部分部署文档和脚本都针对 Linux 环境，Windows 上可能遇到各种兼容性问题。

### Q: 内存不足怎么办？

对于小规模使用（< 100用户），1GB 内存勉强可用，但建议：
- 配置 SWAP 交换空间
- 使用 Redis 而非文件缓存
- 优化 PHP-FPM 配置
- 考虑升级到 2GB 内存
